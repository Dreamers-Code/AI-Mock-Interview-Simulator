# 🎯 InterviewAI — AI Mock Interview Simulator

A premium AI-powered mock interview simulator with real-time feedback and personalized skill assessment reports.

## ✨ Features

- **5 Interview Domains**: Software Engineering, System Design, Data Science & ML, Product Management, HR/Behavioral
- **AI-Powered Questions**: Dynamic, context-aware questions generated by Google Gemini AI
- **Real-Time Feedback**: Instant scoring (1-10) with strengths, constructive improvements, and tips after every answer
- **Personalized Assessment Reports**: Comprehensive score summaries, skill level breakdowns, strengths, growth areas, recommended resources, and next steps
- **Voice Input**: Integrated Web Speech API for hands-free speech-to-text answers
- **Adaptive Difficulty**: Entry Level → Mid Level → Senior Level → Staff/Principal
- **State-of-the-Art Dark UI**: Glassmorphism aesthetic, sleek gradients, responsive design, micro-animations, and printable reports

## 🚀 Quick Start (Local)

### 1. Clone & Install
```bash
git clone https://github.com/Dreamers-Code/AI-Mock-Interview-Simulator.git
cd AI-Mock-Interview-Simulator
pip install -r requirements.txt
```

### 2. Configure API Key
Get your **free** Gemini API key from: [Google AI Studio](https://aistudio.google.com/app/apikey)

Create/edit `.env`:
```env
GEMINI_API_KEY=your_actual_gemini_api_key_here
SECRET_KEY=any_random_secret_string
```

> **Note**: Without an API key, the simulator automatically runs in **Demo Mode** with curated interview questions across all 5 domains!

### 3. Run
```bash
python app.py
```
Open [http://localhost:5000](http://localhost:5000) in your browser.

## ☁️ Deploy to Vercel

### Option 1: One-Click Git Deployment (Recommended)
1. Push this repository to your GitHub account (`Dreamers-Code/AI-Mock-Interview-Simulator`).
2. Go to the [Vercel Dashboard](https://vercel.com/dashboard).
3. Click **Add New...** → **Project**.
4. Import `AI-Mock-Interview-Simulator`.
5. Under **Environment Variables**, add:
   - `GEMINI_API_KEY`: Your Gemini API key from Google AI Studio.
   - `SECRET_KEY`: A secure random string.
6. Click **Deploy**. Vercel will build and deploy your app instantly.

### Option 2: Deploy via Vercel CLI
```bash
vercel
```
When prompted, link to your Vercel team/account (`dreamers-code`).

## 🔧 API Endpoints

| Method | Route | Description |
|---|---|---|
| `GET` | `/api/status` | Check system & AI readiness |
| `GET` | `/api/domains` | List domains, skill tags, and levels |
| `POST` | `/api/session/start` | Start interview session |
| `POST` | `/api/session/:id/answer` | Submit answer & receive instant feedback |
| `POST` | `/api/session/:id/skip` | Skip current question |
| `GET` | `/api/session/:id/report` | Generate comprehensive assessment report |

## 🔐 Security & Best Practices

- **Zero-leak API credentials**: `.env` is ignored by `.gitignore` and never committed to source control.
- **Client & Server Sanitization**: XSS protection on both client side (`escapeHtml`) and server side.
- **Stateless Serverless Resilience**: Cached temporary session recovery ensures smooth interviews even on serverless restarts.
- **CORS enabled**: Supports secure cross-origin requests.
